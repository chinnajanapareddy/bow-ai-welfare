# Street Soul Sanctuary

BOW — AI-Powered Street Dog Welfare & Community Platform

Build a premium, production-quality responsive web application called BOW.

BRAND

Name: BOW

Tagline:
“Every Street Soul Deserves a Second Chance.”

BOW is a technology platform focused on street-dog welfare. It combines AI-assisted welfare triage, citizen reporting, rescue coordination, community stories, responsible food donations, and pet adoption.

The platform should feel like a premium social-impact startup, not a generic animal website.

Example:

Dog

5. AI WELFARE TRIAGE

After uploading an image/video, show a beautiful AI analysis screen.

Example:

✓ Possible swelling

87%

BOW AI does not diagnose medical conditions. This is an AI-assisted welfare assessment and human/veterinary assessment is recommended.

🟢 Low
🟠 Medium
🔴 High

Make the result visually impressive.

If actual AI is not connected yet, implement a realistic demo/mock AI result system and structure the application so a real computer-vision API/model can be integrated later.

6. EXPLAINABLE AI

Every AI result must have a “Why this priority?” section.

For example:

Why High Priority?

Visible wound detected

Abnormal posture detected

Possible swelling detected

Include a visual highlight/analysis area when possible.

Never present the system as a veterinarian.

IMPORTANT PRODUCT PRINCIPLES

AI should assist humans, not replace veterinarians or rescue professionals.

Never present AI output as a medical diagnosis.

Clearly distinguish:

AI observation

Human assessment

Verified information

User-submitted information

Protect user privacy and location data.

Keep the UI premium and uncluttered.

Use real-looking street-dog photography rather than cartoon illustrations.

Use subtle animations, not excessive animations.

Make every major button functional in the prototype.

Use mock/demo data wherever external APIs are not yet connected.

Structure the code so real AI models can be connected later.
